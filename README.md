# Smart Productivity API

A Django REST Framework project with JWT authentication, task management, categories, analytics, and Swagger documentation.

---

## ✨ Features
- JWT Authentication (Register, Login, Refresh)
- Task & Category CRUD (Owner-based access)
- Filtering, Search & Pagination
- Task Analytics & Reminders
- Swagger API Documentation

---

## 🧱 Tech Stack
- Django
- Django REST Framework
- SimpleJWT
- SQLite / PostgreSQL
